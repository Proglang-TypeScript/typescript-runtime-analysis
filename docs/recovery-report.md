## Scope and pipeline boundaries

Inventory covers all five original checkouts and twelve separate inspection clones (nine missing/updated organization components, Jalangi2, JSTYPELOG and JSTYPELOG-Evaluation). Full branch/commit/tag/author/license/manifest/CI records and original statuses are in docs/source-inventory.json. No repository AGENTS.md was found. Relevant sibling remotes were scanned; no additional matching source checkout was discovered.

The original method acquires modules/repositories/READMEs, extracts fenced JavaScript, runs npm-installed examples, calls a service wrapper, and parses/compares resulting declarations. The service uses synchronous files and pinned old release tags, not a required network protocol. The runtime backend records function IDs, argument interactions and returns as legacy JSON containers; Kafka is an optional asynchronous transport. The maintained CLI keeps the file-based boundary and retains the raw artifact separately from shared version1 schemas.

The newest method repository supplies the authoritative coherent comparison component. ts-visitors is a visitor prototype; ts-ast-utils is a separate library with two baseline tests. dts-auto-generate explores sample/test execution but expects an external `/rti/bin/runNew` launcher absent from the inspected master tracer; that historical orchestrator is not reconstructed. js-code-pattern-discovery is static-only and emits frequency summaries; no checked-out dynamic thesis distribution implementation was found. The new binary-shallow-v1 join/predictor is documented as a separate scaffold, with the old extractor preserved.

JSTYPELOG provides later README/LLM generation orchestration and depends on EasyPrompting/API credentials. Its type assignability comparison currently searches compatible exported types without requiring identical export names; it must be reviewed before using it as a quality oracle. It was not imported. JSTYPELOG-Evaluation contains a compressed historical 1,000-package evaluation archive: 56,456 members, 354,680,358 uncompressed bytes, SHA256 b23b5af6830250af7b9803e62df6d5afc798ff698c7d078c7a9ea0d40aa89e4b.
